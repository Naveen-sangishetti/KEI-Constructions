# 🚀 Run Locally

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Naveen-sangishetti/KEI-Constructions.git
```

## 2️⃣ Open Project Folder

```bash
cd KEI-Constructions
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Run Development Server

```bash
npm run dev
```
